Method & boundaries

01

Model detects

XGBoost scores each observed transaction using its contents. This address inherits the highest score from transactions it spends.

02

Graph adds context

Address–transaction links reveal fund flow. Distance to a supplied seed is shown separately and does not prove wrongdoing.

03

Evidence explains

SHAP describes model contributions in log-odds. Patterns show measured structures; equal outputs alone are not suspicious activity.

04

Know the limits

This is a synthetic dataset. Test illicit precision was — and recall —. Synthetic city and ASN values are test fixtures.
